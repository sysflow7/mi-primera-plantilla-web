# SIDeN — Prueba de arquitectura independiente basada en V1.3

Esta rama experimental se ha creado desde `siden-template-v1.3`, por decisión de usar esa versión como base visual y funcional.

- Proyecto independiente por cliente.
- Worker y despliegue propios.
- Configuración e imágenes propias.
- Sin enrutamiento multisite ni dependencia de registro/KV central.
- El sitio corporativo y los Workers existentes permanecen fuera de esta prueba.

Consulta `docs/ARQUITECTURA_INDEPENDIENTE_V1.3.md` para el alcance y las pruebas pendientes.
